BE READY TO EXPLAIN

Why this server?

Round-robin takes turns among the healthy members of the selected pool. Equal turns apply within each pool, not across all paths combined.

What does asyncio do?

While one request waits for network data, the event loop can run another request or a health check. await is where a coroutine can give other work a turn.

Why is this Layer 7?

The balancer reads the HTTP path before choosing a destination. For example, /api/items and /static/style.css use different server pools.
